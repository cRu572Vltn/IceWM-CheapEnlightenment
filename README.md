# IceWM-CheapEnlightenment

This repo contains a recreation of the default Enlightenment WM theme (E17). All assets, except for the taskbar buttons and menus, were taken from the original Enlightenment. Part of the "Cheap X" series, where we port themes to IceWM in the fastest, most careless, and shittiest way possible with horrible quality. This is the only theme publicly uploaded by request of some dumb users.

# Important:

- [Theme used in the screenshot: E17gtk](https://github.com/Peter2121/E17gtk) / [E17gtk revolved](https://www.gnome-look.org/s/Gnome/p/1487007) is also a good option.
- [Icon pack: eDroid](https://www.gnome-look.org/p/2260309)
